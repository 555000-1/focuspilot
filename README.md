# FocusPilot — оптимизатор дня

SaaS-микропродукт: вбрасываешь задачи — алгоритм расставляет приоритеты, строит реалистичный таймлайн дня и запускает фокус-режим. Монетизация: freemium (бесплатно до 5 задач, Pro $9/мес).

## Стек

React 19 · TypeScript · Vite · Tailwind CSS · react-router

## Запуск

```bash
npm install
npm run dev      # dev-сервер
npm run build    # продакшн-билд в dist/
```

## Как включить приём платежей (5 минут, $0 затрат)

1. Заведи бесплатный аккаунт на [stripe.com](https://stripe.com).
2. Создай продукт «FocusPilot Pro» ($9/мес и $79/год) и сгенерируй **Payment Link**.
3. Вставь ссылку в одну строку: `src/lib/planner.ts` → константа `STRIPE_PAYMENT_LINK`.
4. Пересобери (`npm run build`) — кнопка Pro теперь ведёт на настоящую оплату.

После оплаты покупателю выдаёшь активацию (в демо — кнопка «Активировать Pro»). Для полноценной автоматической активации добавь backend с webhook Stripe.

## Что внутри

- `src/lib/planner.ts` — ядро: скоринг задач (важность × срочность × усилия), матрица Эйзенхауэра, построение таймлайна, freemium-лимиты.
- `src/sections/Landing.tsx` — продающий лендинг (hero со «светлячками», тарифы, FAQ).
- `src/sections/Planner.tsx` — сам инструмент: ввод задач, план, таймлайн, фокус-режим с таймером.
- `src/sections/PaywallModal.tsx` — окно апгрейда на Pro.
